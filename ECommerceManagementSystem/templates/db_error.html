🔍 Troubleshooting & Diagnostics

    {% if is_credentials_error %}
  • Issue: Authentication Denied (ORA-01017)
    The username or password provided is incorrect, or the user does not exist in the database.

    To create the user, run these statements in SQL Developer as **`system`**:
    ALTER SESSION SET "_ORACLE_SCRIPT"=true; CREATE USER ecommerce_user IDENTIFIED BY ecommerce_password; GRANT CONNECT, RESOURCE, CREATE VIEW, CREATE SEQUENCE, CREATE TRIGGER, CREATE PROCEDURE TO ecommerce_user; ALTER USER ecommerce_user QUOTA UNLIMITED ON USERS;
    • {% elif is_listener_error %}
  • Issue: Network / Listener Offline
    Flask cannot reach the Oracle service. Check if:
    • Your local Oracle service is running (e.g. look for OracleServiceXE or similar in Windows Services).
    • The connection host or port is correct (default port is 1521).
    • Your DSN (e.g., `localhost/XEPDB1`) matches your local database instance service name.
    • {% elif is_missing_tables %}
  • Issue: Database Schema Missing (ORA-00942 or ORA-02289)
    The user connected successfully, but the tables or sequences are missing.

    Please connect to SQL Developer as `ecommerce_user` and run all the scripts in the sql/ folder:
    • sequences.sql
    • tables.sql
    • trigger.sql
    • procedure.sql
    • sample_data.sql
    • {% else %}
  • General Database Failure
    Confirm your Oracle Database service is online. Make sure you have run the schema compilation scripts (`tables.sql`, `sequences.sql`, etc.) under the `ecommerce_user` account.
